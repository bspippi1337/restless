TERMINAL QUICKSTART

Build locally.
Inspect before running.

RESTLESS is a Go CLI. Use Go 1.24 or newer, then build from the repository. The first harvest command below is a dry run and makes no HTTP requests.

Before enabling network access on another site, confirm ownership or authorization, read relevant terms, and deliberately set the host allowlist. The browser toolbox is separate and never makes API probes.

Debian WSL · macOS · Go terminal
git clone https://github.com/bspippi1337/restless.git
cd restless
go build -o build/restless ./cmd/restless

# Preview only (zero network calls)
./build/restless harvest \
  https://petstore3.swagger.io/api/v3/openapi.json \
  --host petstore3.swagger.io

# After an authorized harvest:
./build/restless index --dir ./archive
./build/restless search "find pet" --dir ./archive
./build/restless plan "find pet" --dir ./archive

Always pass the same --out/--dir archive to each step.

REALITY CHECK

We document boundaries,
not imaginary capabilities.

OpenAPI browser analysis currently parses JSON, not YAML. Its planner does not verify endpoint availability. JWT inspection is unverified decoding. Browser operations do not persist source text or contact a server. RESTLESS 42 is the project initiative, not necessarily the binary version returned by --version.
