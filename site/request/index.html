REQUEST LAB · EXPLICIT NETWORK MODE

Make one request.
Know what happened.

A deliberately restrained browser HTTP console. Inspect public HTTPS APIs you own or are authorized to test, using GET, HEAD or OPTIONS only. No scanning, no retries and no redirect following.

Unlike Toolbox and Contract Lab, this page can send a real network request.

Nothing is sent until you confirm permission, enter an exact approved hostname and press Send. Browser CORS restrictions still apply.

RESTLESS's normal browser Toolbox and Contract Lab remain offline with connect-src 'none'. Request Lab lives on its own route and supports network access only from a deliberate button press and with clear safeguards.

Hard stops

  • GET, HEAD or OPTIONS only
  • Exact approved hostname; public DNS name
  • No raw IPs, localhost or HTTP
  • No cookies, redirects or automatic retries
  • 1–15 second timeout, 2 MB response limit
  • Normal browser CORS enforcement
