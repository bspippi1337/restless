# RESTLESS 42 · v0.5.0-rc.1

**Release candidate: the Toolbox-first developer suite.**

RESTLESS 42 now opens straight into the working **CyberChef-inspired Toolbox**, rather than a marketing-only page. The browser tool has 32 real transformations and a local recipe engine. The documentation portal, OpenAPI Contract Lab, CLI documentation harvester, and native Android utility are packaged alongside it.

## Contents

- **Android native APK:** `RESTLESS-42-v0.5.0-rc.1-Android-debug.apk`. Java/Android application with 32 offline operations, Android document picker and no Internet permission. **Debug signed**, intended for sideload testing. Not Play Store signed; the debug key may change with future builds.
- **Command-line binaries:** cross-compiled and archived for Linux, macOS and Windows. Binary version metadata identifies `v0.5.0-rc.1` and the build commit.
- **Offline website archive:** includes the fully rendered English Field Guide, Browser Toolbox manual and NotebookLM source material. Extract it and serve the directory locally with an HTTP server to use ES module features.
- **SHA256SUMS.txt:** checksums for every release asset, generated by the verified release workflow.

## Highlights

1. **Toolbox-first landing page.** Homepage `https://bspippi1337.github.io/restless/` is the functioning browser workbench.
2. **Real browser QA.** Playwright/Chrome checks JSON transformation, SHA-256, OpenAPI recipe planning, mobile viewport and navigation; screenshots are published as workflow artifacts.
3. **Documentation-first API workflow.** Explicitly permitted, rate-limited harvest → provenance-checked archive → offline OpenAPI index → search → human review plan → contract diff.
4. **Contract Lab.** Inspect and compare two local OpenAPI 3 JSON documents. The change-risk labels are heuristic, not evidence of deployed server behavior.
5. **Portable native Android.** No WebView, no Internet permission, and manually selected document import/export.

## Safety and limitations

This is a **release candidate**, not a stable audited release. The Android app is **debug signed** and should be manually tested on each target device. OpenAPI browser analyzers accept JSON, not YAML. JWT inspection does not verify cryptographic signatures. A generated probe plan makes zero network calls and is not permission to test a system.

Browser Toolbox and Contract Lab never contact a target service. The separate opt-in Request Lab is tracked independently and is **not included unless its pull request has been merged and tested before this release**.

## Quick start

**Browser:** open `https://bspippi1337.github.io/restless/` and choose an example recipe. There is no login.

**Debian/WSL CLI:** extract the matching Linux archive; then run `./restless --help`. If using an unknown download source, verify its SHA256SUMS entry first.

**Android:** download the debug APK and install it on your own Android device using the system installer or `adb install -r`. If Android reports a signing conflict, do not remove a previous installation unless you have exported any user content.

**Offline site:** extract the website ZIP and serve its `site` directory via `python3 -m http.server` or another local static server. Open `http://localhost:8000/`. ES module loading from `file://` may be restricted by browsers.
