THE BOTANICAL WORKFLOW

Six stages. One defensible trail.

Forget random endpoint guessing. Build a library of what the documentation actually says, and keep the evidence attached.

  1. 01 / COLLECT

    Harvest

    Scope-locked, robots-aware retrieval of approved public API docs. Dry-run until explicitly authorized.

  2. 02 / REMEMBER

    Archive

    Store document bytes under SHA-256 and retain source URLs in a JSONL audit manifest.

  3. 03 / UNDERSTAND

    Index

    Extract documented OpenAPI 3 methods, paths, parameters and declared security requirements.

  4. 04 / RETRIEVE

    Search

    Rank known operations and find reference documents locally, with explainable lexical matching.

  5. 05 / THINK

    Plan

    Build source-backed probe plans with human review flags. No requests executed.

  6. 06 / COMPARE

    Diff

    Compare saved API contracts across versions and see additions, removals and changes offline.

THE RULE THAT MATTERS

Documented is not deployed.

RESTLESS distinguishes between what a specification claims exists and what a server has actually verified. Its Botanical search is deterministic lexical ranking, not an LLM semantic engine. A proposed plan is never evidence that an endpoint is live.

Quiet by design

  • No blind endpoint fuzzing in Botanical
  • No automatic calls from a probe plan
  • No assumed authorization from robots.txt
  • No invented APIs when evidence is missing
  • Revalidation can reuse unchanged documents via HTTP 304
